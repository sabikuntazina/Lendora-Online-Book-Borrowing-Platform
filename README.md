# 📚 Lendora – Online Book Borrowing Platform

## 🚀 Project Name
Lendora

---

## 🎯 Project Purpose
Lendora is a modern & online book borrowing platform built with Next.js. It is a seamless and modern web application designed to digitize the traditional library experience. Users can explore a vast collection of books, filter by categories, and borrow titles digitally. The platform prioritizes security and performance using BetterAuth, Next.js, and MongoDB.


The system allows users to:
- Browse books
- View detailed book information with login
- Borrow books securely
- Manage user profiles
- Access protected routes using authentication

The main goal of this project is to simulate a real-world library system with authentication, protected routes, and user-based features.

## 🔐 Authentication System

Lendora includes a complete authentication system:

- 🔑 Sign In functionality
- 📝 Sign Up functionality
- 🛡️ Protected routes (only signed-in users can access book details)
- 🔒 Proxy-based route protection using Next.js
- 🚪 Signout functionality

Users must be authenticated to:
- View book details
- View Profile
- Access restricted pages

## 👤 User Profile System
